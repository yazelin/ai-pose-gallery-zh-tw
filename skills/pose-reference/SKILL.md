# 姿勢參考圖

資料來自 [ai-pose-gallery](https://ai-pose-gallery.pages.dev/)（作者 ギア），繁中翻譯版每日同步。

## 怎麼找

```bash
python3 pose.py search 關鍵字 [關鍵字...] [--angle 角度] [--line 系列]
```

- 多個關鍵字要全部符合，比對 id、系列、分類、姿勢名稱。
- 角度：`正面`、`從上方`、`從下方`、`側面`、`斜側`。
- 系列：`全身1人・標準系`、`全身1人・性感系`、`上半身1人`、`2人交纏`。
- 每行輸出：`id  系列｜分類｜姿勢名稱｜角度  原尺寸圖網址`。

不想跑腳本，也可以直接讀 <https://yazelin.github.io/ai-pose-gallery-zh-tw/poses.json>。每筆欄位是 `id`、`series`、`pose_no`、`category`、`name`、`angle`、`thumb`、`image`。

分類有：站立、坐姿、蹲姿、跪立、趴躺、前傾、扭轉、後仰・反弓、可愛系、臉部靠近類等，2 人系列另有雙人體位分類。找不到時換同義詞，例如「托腮」「撐地」「抱膝」「回頭」「撥髮」。

## 怎麼用

1. 用 search 找到候選，挑一個姿勢。看圖確認時用縮圖網址（`thumb`）就夠了。
2. 下載原尺寸 PNG（900×1200）當參考圖：
   ```bash
   python3 pose.py get <id> [<id>...] -o pose-refs
   ```
3. 交給生圖或生影片工具的姿勢參考、構圖參考或參考圖輸入。ControlNet 類工具可以當 lineart 或 openpose 的前處理來源。
4. 提示詞裡另外寫臉、髮型、服裝、背景。圖本身是無臉灰色人台線稿，這些都要用提示詞或其他參考圖（例如臉部參考）補上，也要明說「姿勢照參考圖，不要畫出人台的關節線與灰色」。
5. 同一個角色要連續出好幾張時，固定用同一個姿勢的不同角度（同一個 `pose_no`），姿勢比較容易一致。

## 規範（原站注意事項）

- 可免費用於自己的作品，商業使用、編輯、參考都可以，不必標註出處。
- **禁止再散布圖片本身**，原尺寸和加工後的都算。下載的 PNG 只能留在本機當參考，不要 commit 進公開 repo，也不要放上網站或分享出去。
- 不得用於表現真實人物或未成年人，也不得用於違反公序良俗的用途。
- `全身1人・性感系` 與 `2人交纏` 系列含性暗示與性行為姿勢。使用者沒要求時，從 `全身1人・標準系` 和 `上半身1人` 找。
